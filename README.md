# Buddha Mayoori Constructions

A production-quality full-stack web application for Buddha Mayoori Constructions, built using React, Express, and MongoDB.

## Project Purpose
To deliver an authoritative, accessible, high-performance public web platform and admin portal for Buddha Mayoori Constructions, showcasing construction capabilities, portfolio projects, client inquiries, and business administration.

## Technology Stack

### Frontend
- **Framework & Libraries**: React, React Router
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **HTTP Client**: Axios
- **Iconography**: Lucide React

### Backend
- **Runtime**: Node.js
- **Web Framework**: Express.js
- **Authentication**: JSON Web Tokens (JWT), bcrypt / bcryptjs

### Database
- **ODM & Database**: MongoDB, Mongoose

### Tooling & Version Control
- **Version Control**: Git & GitHub

## High-Level Architecture

`
[ Client (React + Vite) ] <---> [ REST API (Express.js) ] <---> [ MongoDB Database ]
`
- **Client App (/client)**: Decoupled Single Page Application (SPA) handling UI/UX, page routing, dynamic state management, and user interaction.
- **Server App (/server)**: Decoupled Node/Express backend handling API endpoints, authentication, business logic, validation, and data persistence with Mongoose.
- **Documentation (/docs)**: Central repository for project documentation, setup guides, requirements, and architectural design records.
